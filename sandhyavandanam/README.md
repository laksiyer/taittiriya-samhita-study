# सन्ध्यावन्दनम् · Sandhyāvandanam Study

An Obsidian-ready companion to the Taittirīya Saṃhitā study project. **Gopīnātha Dīkṣita's Saṃskāraratnamālā** is the principal *ādhār grantha*. This is a developing source-critical study, **not yet a verified performance manual**.

## Start here

Open [[00-Start-Here]] in Obsidian. All study notes are ordinary UTF-8 Markdown files, readable and editable offline. The `index.html` file is the existing stand-alone website prototype. The Markdown is presently the editable working source; the HTML does **not yet automatically import** these notes.

## How to install

1. Extract the ZIP to a working folder, preferably inside your existing `taittiriya-samhita-study` repository as `sandhyavandanam/`.
2. In Obsidian, open your **existing** vault that contains the repository, or use **Open folder as vault** on a folder containing this directory.
3. Open `sandhyavandanam/00-Start-Here.md`. Obsidian `[[wikilinks]]` work after extraction.
4. Edit `.md` notes freely and commit the changes through your normal Git workflow. Nothing in this ZIP overwrites TS chapters.
5. For GitHub Pages, `sandhyavandanam/index.html` can be served at `/sandhyavandanam/` after you add and push the folder to the published repository.

## Editorial rules

- Keep actual Vedic or Sūtra injunctions distinct from later ritual digests, Purāṇic/Āgamic additions, and contemporary usage.
- 'Not documented here yet' is **not** equivalent to 'omitted by this tradition'.
- Distinguish **Veda**, **śākhā**, and **sūtra**; do not conflate Baudhāyana, Āpastamba, and Hiraṇyakeśin.
- Quote exact Sanskrit only when verified against a named edition, with page/section references.
- Sanskrit and English only; English explanations should not be transliterated by the eventual site script selector.
- No em dashes in site prose or study notes.
