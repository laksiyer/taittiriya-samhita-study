# शाखासूत्रविभागः · Tradition map

A Veda is not the same entity as a śākhā, and a śākhā is not identical to one Gṛhyasūtra. The website should track the levels separately.

| Veda family | Starting source traditions | Current scope |
|---|---|---|
| यजुर्वेदः, Kṛṣṇa Yajurveda, Taittirīya | **Baudhāyana**, **Āpastamba**, **Hiraṇyakeśin** | First deep procedural comparison |
| ऋग्वेदः | Āśvalāyana, Śāṅkhāyana | Add after source collation |
| सामवेदः | Gobhila, Khādira | Add after source collation |
| अथर्ववेदः | Kauśika and other relevant materials | Establish evidence and scope first |

## Dimensions of selection

`Veda → śākhā → sūtra/prayoga tradition → prātaḥ / mādhyāhnika / sāyam`.

The user interface may initially hide the śākhā step when unambiguous, but source records should retain it. A switch of ritual tradition must eventually switch **verified ritual content**, not merely the label.
