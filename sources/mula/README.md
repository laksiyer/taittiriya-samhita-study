# Mūla witness register

We do **not** treat Sāyaṇa OCR as an accent source. The first witness is the [independent accented text](https://sanskritdocuments.org/doc_veda/taittirIyabrAhmaNam.html), TB 1.1.1. It has restrictions on reproduction. Keep links and only short excerpts until permission or an independently usable edition is identified. Cross-check with a printed accented edition and log variants before release.
